Plugins





Plugins Claude Code installés via marketplace



ℹ Pas de Start/Stop/Restart sur les plugins

Un plugin n'est pas un process - c'est un bundle (manifest JSON + fichiers) qui peut contenir des MCPs, skills, commands, hooks. Pour relancer un MCP fourni par un plugin, retrouve-le dans la tab Serveurs MCP avec ses boutons Stop/Démarrer/Redémarrer dédiés. La case à cocher ici contrôle uniquement si le plugin est enabled dans ~/.claude/settings.json.
